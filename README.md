# Java Algorithmic Problem Solver

A curated collection of optimized Data Structures and Algorithms (DSA) solutions written in pure Java. 

## Technical Focus
* **Array Manipulation:** Efficient sub-array calculations (e.g., Maximum Subarray/Kadane's Algorithm).
* **String Processing:** Two-pointer approaches and compression algorithms (Run-Length Encoding, Anagram validation).
* **Collections Framework:** Utilization of HashMaps for optimized time-complexity lookups.

This repository serves as a log of my active preparation for competitive programming assessments and technical interviews, focusing on writing clean, scalable, and memory-efficient logic.
